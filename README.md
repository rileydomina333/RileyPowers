</p>📱 METODO 1: TERMUX (Android)

Apri Termux e incolla questi comandi uno alla volta:

1. Preparazione:
   
   pkg update && pkg upgrade -y
pkg install git nodejs -y

2. Clone del Bot:
   
   git clone https://github.com/rileydomina333/RileyPowers.git
cd RileyPowers

3. Avvio:
   
   npm install
npm start

---

💻 METODO 2: VPS (Linux/Ubuntu)

Per chi vuole il bot attivo 24 ore su 24.

1. Installazione Core: Assicurati di avere Node.js e Git sulla VPS.

2. Persistenza con PM2:
   
   npm install -g pm2
pm2 start index.js --name "riley-bot"
pm2 save
pm2 startup

3. Monitoraggio:
   
   pm2 logs riley-bot
   
   Usa questo comando per visualizzare il QR Code e i log del bot.
